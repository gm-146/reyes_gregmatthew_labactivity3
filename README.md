## Description
This project implements a practical mini-system for Inventory Monitoring using Python. It demonstrates Object-Oriented Programming (OOP) concepts by utilizing two related classes: `Product` and `Inventory`.

## Requirements
* Python 3.14.6
* Anaconda Environment

## How to Run
1. Open your Anaconda Prompt or PowerShell.
2. Navigate to the main project directory: 
   `cd reyes_gregmatthew_labactivity3`
3. Activate the conda virtual environment (if applicable):
   `conda activate lab3_env`
4. Run the script from the source folder using the following command:
   `python source/inventory_system.py`

## Test Cases Included
When you run the script, it will automatically execute three meaningful test cases:
1. Adding Products: Instantiates `Product` objects and adds them to the `Inventory`.
2. Selling Items: Tests reducing product stock, including a check for insufficient stock.
3. Restocking Items: Tests increasing the stock of existing products.
